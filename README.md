# ledblink_FreeRTOS
3 Different Delay for the LED blink using STM microcontroller
In this repository, I used STM32446RE development board.
3 external LEDs are connected, each with a separate delay.
FreeRTOS (version FreeRTOSv202012.00) was added externally to the STM32 project folders, and the code was developed using it.
